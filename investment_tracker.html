Add Transaction

Log one buy/sell/dividend event. Buy: price = cost/unit paid. Sell: price = selling price/unit (doesn't change your cost basis). Dividend: extra units credited, cost/unit optional.

Add Unit Rate (NAV)

Record the market rate for a fund on a given date — used to value your holdings and compute P&L. One rate per fund per month recommended.

Value Trend

Line chart of value over time. Cost Price = money invested; NAV-based Value = units × NAV for that month; NAV Rate = the fund's raw rate only (isolates fund performance from your buying activity — requires a single fund selected). No fund = whole portfolio (rate option excluded).

Mutual Funds Projected

Invested Till = which transactions to include (snapshot cutoff). Projected Year/Month = the date you're valuing as of (drives growth & NAV lookup). Assumed Return % is per fund, editable.

Lot-wise Projection

Each buy/dividend = a lot. Open = still growing at the assumed rate to your target date. Closed = that portion was sold, growth stops at sale (frozen value, no projection). Total Actual pulls the real NAV rate for that exact fund+year+month; shows a message if none exists.
